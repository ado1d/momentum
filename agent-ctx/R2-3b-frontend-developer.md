## Notes for future agents
- agent-browser CLI shares ONE default browser across all agents in this environment — when parallel agents are active, always test with `--session <name>` or your DOM/screenshot checks will race against the other agent's navigation.
- Tailwind 4 emits hover-variant rules inside `@media (hover: hover)`; headless Chromium here reports hover:none, so group-hover styling cannot be verified in the headless browser — verify presence of the classes + rely on real-device behavior.
- Query key ["insights"] is owned by InsightsView; invalidate with the plain prefix after any mutation that changes completed todos / habit checks / journal moods / focus sessions so analytics refresh.
